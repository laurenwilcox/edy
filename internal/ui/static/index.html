Поиск по смыслу

Агенты находят код не только по словам, но и по смыслу: «где проверяется пароль» найдёт checkCredentials. Куски кода и заметки памяти превращаются в векторы моделью эмбеддингов (OpenAI-совместимый провайдер: Ollama — бесплатно и локально, OpenAI, OpenRouter…). Перед каждой задачей индекс обновляется сам — пересчитываются только изменённые куски.

Как оформлять результат агента

Клонировать репозиторий

Репозиторий скачается в папку Edy и появится в списке проектов.

Аккаунты GitHub, GitLab, Gitea

Токен хранится зашифрованным и передаётся git только на время команды — в настройки репозитория он не записывается.
Постоянные агенты проекта. У каждого роль, зона и своя память: после каждой задачи он помнит, что сделал и на чём споткнулся. Оркестратор отдаёт им задачи из их зоны; вручную агента можно выбрать в списке «Исполнитель».

Новый агент

Каталог внешних MCP-серверов. Оркестратор видит их описания и сам решает, какие выдать исполнителю под задачу: в плане появляется строка «MCP: …». Исполнитель с поддержкой MCP (Claude Code) получает их вместе с MCP Edy. Файлы проекта он всё равно правит только через Edy.

Добавить сервер

Заголовки и переменные хранятся зашифрованными. Сохранение с тем же именем заменяет сервер.

🔔 Уведомления

💰 Дневной бюджет

Когда расходы за день на API дойдут до лимита, Edy перестанет отправлять платные запросы. 0 — без лимита.
