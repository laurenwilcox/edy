MCP — инструменты Edy для внешних агентов

Claude Code, Gemini CLI, Cursor и другие MCP-клиенты получают инструменты Edy для текущего проекта: карту проекта и поиск по коду, чтение и правку файлов (только внутри проекта), проверки (тесты и линтеры) и скиллы. Каждая правка сохраняется снимком — её можно откатить в разделе «Проект». Подключения видны в окне «Агенты».
